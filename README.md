# 亲手为自己造一本教材

> 写给不懂技术、想给自己（或孩子）造一本教材的人。

## 这是什么

你手上有一本教材，或者只是有一个想学的领域。把它交给 AI 助手，它陪你造出一本属于你自己的书：
先读材料，定下设计，写一章定下写法，铺完整本，最后从头检查一遍。

成品默认是教学蓝本，给 AI 苏格拉底老师读的。老师拿着它，用提问把一门课教下去。也可以选给人读的
流畅教材，正文是叙事，章末带练习和讨论题。手头一份材料都没有也能从零造，但那只适合 AI 本身讲得
清的领域。

要你动手的有三样：准备材料，弄一个 MinerU Token（一次就够），在它停下来的时候回答
「这样对不对」。装依赖、建目录、把 PDF 转成文字，这些是 AI 的活，卡住了它会来问。开工后
第一件事是选路线：给 AI 老师上课的教学蓝本，还是给人读的教材。之后设计期还有三次确认——
材料读完，它先把重点难点和三到五条学习目标摆给你看；再往下是教学方法与章节板块；最后一次
是全书结构和章节安排。这几次都过了，它才动手写正文。

谁适合用：手上有教材、教师用书、考纲、讲义或真题，想把它整理成一门课的人。自己带孩子的家长，
备课的老师，做教研的老师。全程中文。

## 三分钟装起来

装之前确认一件事：你的 AI 助手得能读技能目录。判断标准只有一条，它认「技能目录」这个说法，
按目录名能找到里面的 `SKILL.md`。

### 第一步：装技能

在 AI 助手里说一句，地址带上，它才知道去哪儿装：

```
安装技能 craft-your-textbook：https://skillhub.cn/skills/craft-your-textbook
```

SkillHub 是国内打开快的那个技能站；同一个技能也发布在 GitHub 上，地址是
`https://github.com/xx-hub/craft-your-textbook`。两边装哪个都行，想拿到最新的一版就走 GitHub。

装不上就手动来：把仓库 clone 下来，`skills/craft-your-textbook` 这个文件夹整个丢进你的 AI 助手的
技能目录。

`SKILL.md` 是唯一入口，文件夹放进去就算装好。各家的技能目录位置不一样，以你那个助手自己的
文档为准。想跟着仓库更新，就别拷贝，改成软链接指向 clone 出来的那一份。

### 第二步：给一个 MinerU Token

教材是 PDF，AI 得先把它转成文字才读得懂。这一步走 [MinerU](https://mineru.net)：注册，
申请一个 API Token，免费额度够造一本书。第一次对话时把 Token 贴在消息里就行。装依赖、跑转换、
按学科决定要不要公式识别，都是 AI 的事；它真卡住了会来问你。

Token 只在这台机器上用，别写进书稿，也别提交到仓库。

### 第三步：第一次对话说什么

新开一个对话，把材料在哪、想要什么书、Token 是什么说清楚：

> 帮我造一本《人教版七年级上册英语》的教学蓝本。学生用书在 `/Users/你/教材/七上英语.pdf`，
> 教师用书在 `/Users/你/教材/七上英语教师用书.pdf`。MinerU Token 是 `xxxxxx`。

路径换成你电脑上的真实位置，Windows 上形如 `C:\Users\你\教材\七上英语.pdf`。

AI 会先问你：这本书是给 AI 老师上课用的教学蓝本（默认推荐），还是给人读的流畅教材？选完它开始
读材料。读完先把重点难点和它拟的三到五条学习目标摆给你看，你确认这两样对不对。再往下它逐个
提案：教学方法与章节板块，然后是全书结构和章节安排。这几次都在对话里问，你说行就往下，说不行
就说哪里不对，它改完再问一遍。

设计定了才动笔。它先写一章当全书的样子，另起一个不懂上下文的审计员挑错，再按这一章把写法定死；
之后各章并行铺开，每章写完都过一遍审计。接近交付时，它把整本书连起来再查一遍，专挑单看每章都
对、连起来不对的地方。你不需要懂技术，回答「这样对不对、要不要改」就够了，随时也可以让它改某
一章、某一处。

交付时你会拿到一份 Markdown 成品书，书就在你给的项目目录里，不在别处。

## 方法论说明：为什么这样造书

### 书首先是给 AI 老师读的

AI 老师会读完整本书，把它当上课的输入。所以书里每个字都要服务一件事：它怎么用这本书上课。
书对老师有四个用处，内容锚定（防跑题、防编造），知识结构（一条推理主线），弹药库（案例、例题、
词条随取随用），提问路线图（用什么问题把学生引到知识点上）。

最容易犯的错，是把蓝本当纯文学作品写。开篇写一个「读者读到这里会想……」的钩子，通篇跟「你」
对话，却不写清「你」指谁。AI 老师不需要钩子，它需要的是能拿来上课的东西。

### 两条路线，开工时选一条

教学蓝本只给场景、知识点、提问路线图，绝不写死「老师说……学生答……」的对话脚本。写死了，
AI 老师会照抄，教学就死了。它要的是结构化的提问方向和问题链。

流畅教材的正文是叙事，不内嵌给 AI 老师的元指令。每章末尾有教学素材区，练习、讨论题、教学脚本
都在那儿，那就是老师的提问路线图。成书时会在开头注入一段给老师看的说明。

两条路线互斥，默认推荐教学蓝本。

### 六个阶段

| 阶段 | 做什么 | 你在这里做什么 |
| --- | --- | --- |
| 一、源材料准备 | PDF 转成文字，材料理清楚 | 交材料、给 Token |
| 二、源探查 | 摸清材料结构、分清主次、标出谁是谁，做事实校准 | 第一次确认：它读得对不对、那三到五条学习目标行不行 |
| 三、教学设计 | 定路线 → 选章节板块 → 设计全书架构 → 排章节 | 第二次确认：教学方法与板块；第三次：全书架构与章节安排 |
| 四、最佳范例章 | 先写一章，独立审计过再定下全书的写法；条件具备时还会试教一次 | 想看就要，觉得写法不对就说 |
| 五、全量写作 | 按这一章的样子并行铺其余章，逐章挑错，整本连起来再查一遍 | 随时指某一章、某一处提意见 |
| 六、交付 | 终检、拆掉造书过程留下的脚手架、逐项过交付前检查 | 收成品书；有不满意的说，它改完重过一遍检查 |

### 核心设计：不套模板

书的形状由 AI 按你的材料与目标来定，从一批模式卡里选、混搭，或者新造。卡片分五类：概念怎么
锚定，练习怎么分层，叙事怎么搭，整书架构怎么摆，语言学习怎么特化。每张卡解决一个具体的教学问题。

选的时候必须回答两个问题：拒绝了哪些卡，为什么；选中的每张卡对应本书哪个教学问题。不变量是底线，
模式库是菜单。四件契约产物——写作规范、章节骨架、源材料索引、风格与语法——把设计逼到说清楚；
另有一条风格线，你随时补一句写法意见，它就追加进去。

### 有教师用书，就能直接针对应试

教师用书里藏着评价标准与教学目标，那就是命题的靶心；还有学情分析与常见错误，预判学生会栽在哪儿；
考点与题型提示；以及比学生用书深一层的讲解。

有了它，AI 老师带的不只是讲解，还有考点意识，能把你引到考试要求的水平。单靠学生用书做不到这一点，
这也是「学生用书 ＋ 教师用书」被设为默认流程的原因。

### 书太厚，可以让它薄一点

读完材料、定章节之前，AI 会问一句：按材料全覆盖，还是先确认你已经会什么、把会的削掉？选后者，
它先出一份问卷，照你的回答出一张知识点图，削掉的部分在图上留标记，想放回来随时能放。

### 质量靠什么守

每章写完，另有一双眼睛从头挑错，只看成品，不看写手的自辩。最佳范例章还要试教一次（条件具备时才跑），
试出来的问题回填进全书的写法，后面每章都照它写。

合并前再整本查一遍，专挑单看每章都对、连起来不对的地方：说法打架，术语不统一，交叉引用指错，
知识点断层。

交付前把脚手架拆干净。版本标记、自检清单、修订日志、「教师用书说……」这类对只读一本书的
AI 老师零价值的元数据，都该消失。拆完再用交付前自查表逐项过，一项不落地过完才允许交付。
机器能判的那几项有现成脚本，AI 自己跑，跑不过会点名到章、到行。

多轮迭代是常态。平均每本书 5-7 轮审校，别指望一次成型。

### 适用面

任何学科都能用：英语、语文、数学、物理、历史、编程、认证考试。不预设板块骨架，语言类启用
词汇分层卡，理科和认证类启用公式、判断题卡，叙事类启用主角、贯穿案例卡。没有「按学科硬分」
的表格，只有「按教学问题选模式」。

这套方法把重活拆给几路并行的子代理：精读材料、写作、逐章挑错、跨材料对齐、图的审校。

### 这份方法背后的信念

过去做不到「引导」，是因为引导太贵。一个学生每天学 8 小时，就得一位老师全职陪 8 小时，
还得备课。引导不起，于是教学只能是灌输。

AI 第一次让另一种可能成立：完全定制化的私人教材，全天候无限精力的私人教师，最适合你的引导方法。
而这条路最基础的一块砖，就是把一份素材加工成「AI 老师能沿主线教学、不跑题、不幻觉」的书。
这正是这个技能做的事。
